# Winter School in Astronomical Calculations using Python Programming

### December 2024 – January 2025

This repository contains my notes, Python notebooks, and exercises from the *Winter School in Astronomical Calculations using Python Programming*. The school introduced a wide range of topics in modern astronomy and astrophysics, while emphasising computational approaches to data analysis, modelling, and visualisation using Python. This repository serves as a personal record of my learning during the winter school and as a collection of notes and code that I can build upon in future astronomy and astrophysics projects.

## Topics Covered
- Heliophysics and Solar Physics
- Astronomical Coordinates and Distance Measurements
- Solar System Dynamics and Orbital Mechanics
- Stellar Structure and Stellar Evolution
- Star Formation and Stellar Clusters
- Exoplanet Detection and Characterisation
- Black Hole Jets and X-ray Binaries
- Galaxies and Active Galactic Nuclei
- Radio, Optical, and X-ray Astronomy
- Gravitational Lensing and Gravitational Waves
- Cosmology and the Large-Scale Structure of the Universe
- Dark Matter, Dark Energy, and the Cosmic Microwave Background
- Multi-Messenger Astronomy

## Computational Tools
Throughout the school, we worked with Python, exploring the following Libraries:
- **Numpy** for numerical computations and array-based scientific calculations.
- **Pandas** for data handling, preprocessing, and exploratory analysis of astronomical datasets.
- **Matplotlib** for visualisation of observational data, simulations, and scientific results.
- **Astropy** for astronomical data analysis, coordinate transformations, units, and astrophysical utilities.
- **Sunpy** for solar data retrieval, analysis, and visualisation for heliophysics applications.
